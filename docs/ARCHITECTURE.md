# 架构说明

## 完整应用

Vue 3、TypeScript、Element Plus 和 Pinia 构成界面层，Vue Router 管理角色路由。Axios 访问 FastAPI，业务数据由 SQLAlchemy 管理。课程片段进入 SQLite 检索存储，使用本地 TF-IDF 与中文关键词完成召回；大模型生成结果经过质量检查与教师审核后供学生使用。

后端保留原有十智能体编排、测评、学习画像、学习路径、资源和报告服务。Electron 桌面端使用相同的前后端，实现本机打包运行。模型配置仍由后端读取，不转移到浏览器。

## Pages 展示适配

`npm run build:showcase` 使用独立的 Vite 模式。`src/config/runtime.ts` 识别该模式；路由改用哈希形式，Axios 请求层加载 `src/showcase/adapter.ts`，从 `public/showcase/snapshot.json` 读取数据。页面与图表仍由现有 Vue 组件渲染。

适配器保留后端响应结构、角色范围、课程筛选、资源类型筛选和报告下载。每次返回独立数据副本，页面临时编辑不会污染快照。除展示账号登录外，写入请求统一拒绝并说明需要完整服务。页面标注“前端展示 · 只读”。

`npm run build` 和原有启动脚本仍采用完整服务模式；展示适配器不参与真实鉴权或业务生成。展示会话按网站基础路径隔离，避免同一 GitHub 用户的不同仓库共享登录状态。

## 数据来源

快照导出脚本只使用程序自带课程和样例账户，在独立临时 SQLite 库中启动真实应用并读取 API。导出结束后清理临时库。JWT、密码散列和本机路径不会进入快照；角色令牌仅是公开演示人物的选择标识，不具备认证意义。

快照固定提交，以便每次 Pages 发布保持一致。报告 PDF 和 Markdown 从后端报告接口生成，文件名按内容摘要命名。没有模拟新的线上任务或添加虚构的学习效果数据。
