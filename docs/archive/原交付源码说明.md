2026 年 iCAN AI 应用创新挑战赛，软件赛道。

## 环境

- Python **3.12**。
- Node.js **24.x**（本次验证版本 24.13.0）及 npm。Vite 8 至少要求 Node 20.19 或 22.12；推荐使用本次验证主版本。
- Windows 源码运行需要 Python Launcher（`py -3.12`）和 PowerShell。
- 首次安装依赖需要网络；依赖安装完成后默认 Mock 模式可本地运行。

## macOS / Linux 一键启动

在本目录打开终端：

```bash
bash scripts/start_dev.sh
```

脚本会从 `.env.example` 创建本地 `.env`，创建 `.venv` 并安装前后端依赖，然后启动应用。

浏览器访问 `http://127.0.0.1:5173`。后端健康检查为 `http://127.0.0.1:8000/api/health`。首次启动会自动创建演示库。按 Ctrl+C 停止服务。macOS 也可以双击 `scripts/start_dev.command`。

端口被占用时：

```bash
BACKEND_PORT=8001 FRONTEND_PORT=5174 bash scripts/start_dev.sh
```

## Windows 源码启动

在本目录打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_windows.ps1
```

此设置仅用于本次脚本进程。脚本自动安装依赖，并打开前后端两个控制台及浏览器；关闭两个控制台即可停止。无需源码调试时，优先使用包内 Windows 安装器。

## 手动运行与复测

macOS / Linux：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
PYTHONPATH=backend .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另一个终端：

```bash
cd frontend
npm ci
npm run dev -- --host 127.0.0.1
```

依赖与后端测试：

```bash
.venv/bin/python -m pip check
PYTHONPATH=backend .venv/bin/python -m pytest backend/app/tests -q
```

前端质量检查与构建：

```bash
cd frontend
npm run lint
npm run typecheck
npm test
npm run build
```

生产构建输出 `frontend/dist`。此目录为构建产物，不随源码重复提交。Python 依赖范围见 `backend/requirements.txt`；前端与桌面构建依赖版本分别由各自 `package-lock.json` 锁定。本次 Python 实际解析版本保存在上级 `verification/python_environment.txt`，该记录用于复核，不作为跨平台安装脚本。

## Docker Compose

已安装 Docker 与 Compose 时，可在本目录执行：

```bash
cp .env.example .env
docker compose up --build
```

默认前端 `127.0.0.1:5173`，后端 `127.0.0.1:8000`。数据持久化在命名卷中。此方式作为源码提供的可选部署入口，本次 iCAN 交付是否复验以 `../03_交付与验证说明.md` 为准。

## 初始化数据

空库首次启动会自动初始化。需要显式补齐演示数据时：

```bash
bash scripts/init_demo_data.sh
```

`bash scripts/init_demo_data.sh --reset` 会重建演示库，并先备份旧 SQLite，仅在确认不需要当前演示数据时使用。

## 工程结构

```text
backend/app/agents/        十个专职 Agent、编排器、Prompt
backend/app/rag/           文档解析、分块、课程隔离检索
backend/app/services/      画像、路径、质量、测评、报告、LLM Provider
backend/app/api/routers/   认证及三角色业务接口
backend/app/models/        SQLAlchemy 持久化模型
backend/app/tests/         接口、业务、权限、模型策略测试
frontend/src/             Vue 3 / TypeScript 前端和组件测试
demo_data/                三门演示课程及验收资料
desktop/                  Electron 壳及桌面后端入口
scripts/                  开发启动、初始化、导出及安装器构建
.github/workflows/        可手动触发的 Windows 原生安装器验收流程
```

## 核心业务能力

学生：注册/登录、选课、个人设置、前测、画像、路径、讲义、图谱、练习、错题、后测、对比及报告。

教师：课程管理、资料解析、知识点与关系编辑、资源生成、Agent 运行观测、教师修订/审核/发布、题库、班级看板及报告。

管理员：用户启停、角色治理、应用与模型状态、Agent/LLM 日志、白名单字段的数据快照。

检索使用 SQLite 中的文本片段、字符 TF-IDF 与词项重叠；没有接入外部向量数据库或 OCR。多模态 Agent 输出 PPT 大纲、视频脚本、实验方案等结构化资源，不宣称自动渲染成音视频或实物。

## 桌面版构建

```bash
bash scripts/build_macos_installer.sh arm64
# Intel Mac 或配置对应 x86_64 Python 后：
bash scripts/build_macos_installer.sh x64
```

完整 Windows/macOS 打包入口、Windows runtime 组装及原生验收脚本均保留在 `scripts/` 和 `desktop/`。既有三份安装器位于上一级 `installers/`；重新打包需要下载 Electron 等目标平台依赖，属于开发流程。
