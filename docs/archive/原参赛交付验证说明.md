## 校验方法

macOS/Linux 在本目录执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Windows PowerShell 可对单个安装器核对：

```powershell
Get-FileHash .\installers\Windows\XunkeFlow_Windows_1.1.0_x64_Setup.exe -Algorithm SHA256
```

根目录 FILE_MANIFEST.tsv 包含路径、字节数、SHA-256；SHA256SUMS.txt 覆盖所有载荷文件与清单文件，自身不递归包含。第三方许可文本保存在 `licenses/`。
