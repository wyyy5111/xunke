## 四分半体验顺序

下面是方便评审快速理解的操作建议，不替代单独提交的演示视频。

1. **0:00—0:30，课程与目标。** 教师登录后进入课程，查看课程资料、章节和知识点。当前系统预置三门跨学科演示课程，可直接体验。
2. **0:30—1:00，课程证据。** 在资料与知识体系工作台查看已解析课程片段及知识点关系。需要重新上传时，可选择 `demo_data/` 中的 Markdown 课程资料。
3. **1:00—2:00，Agent 协作。** 进入智能体指挥舱，选择课程并启动完整协作任务；观察解析、图谱、诊断、规划、讲义、导图、练习、多模态资源、质量门控及教师预审十个节点。查看本次新生成的 trace、各步骤状态、输入输出摘要及引用。
4. **2:00—2:40，质量与教师控制。** 查看生成资源、课程引用和质量评分，进入教师审核流程；教师可以修订资源，审核后显式发布。未发布资源不会作为学生公共学习内容出现。
5. **2:40—3:50，学生学习闭环。** 退出教师账号，登录 student01，进入课程，查看前测、画像与路径；体验讲义、导图、练习/错题和后测对比，再导出个人学习报告。
6. **3:50—4:30，治理与追踪。** 管理员登录后查看用户启停、模型状态、Agent/LLM 记录和数据快照，确认当前模式与任务记录一致。

预置资源和历史任务用于快速展示。若要验证当前调度实际执行，请主动启动一个新任务并查看新的 run/trace；新任务数据会写入本机演示数据库。

## 完整操作路径

**教师建课与知识库：** 创建/编辑课程 → 上传 PDF、DOCX、PPTX、TXT 或 Markdown → 解析 → 查看课程片段 → 编辑章节/知识点及关系 → 检索核对引用。扫描图像型 PDF 目前没有 OCR，请使用包含文本层的资料。

**个性化学习：** 学生加入课程 → 完成前测 → 设置学习目标和每周时长 → 生成画像/路径 → 查看学习资源 → 练习与错题 → 完成后测 → 查看已覆盖知识点的比较和报告。未被后测试卷覆盖的知识点会被标记为待复测，不作为新的效果证据。

**资源生产：** 选择课程并使用已有代表学生画像（API 支持指定学生） → 启动 Agent 流程或单类资源生成 → 查看资源、引文和质量报告 → 教师修订与审核 → 发布。多模态资源目前为 PPT 大纲、视频脚本和实验方案等结构化内容。

**班级与运维：** 教师查看班级画像与前后测汇总；管理员查看账户、应用状态和生成日志。数据快照用于查看白名单业务字段，不是整库恢复备份。

## 常见问题

- **为什么无需 Key 也能生成？** 当前为 Mock 模式，本地模板驱动内容生成；课程检索、画像、调度、数据库和审核流程仍实际执行。
- **真实 AI 在哪里配置？** 桌面菜单“应用 → 打开用户数据目录”内的 `.env`；源码运行在 `.env`。修改后完整退出并重启。见 `02_模型配置与数据说明.md`。
- **为什么有知识点待复测？** 后测试卷没有覆盖该知识点，系统不把沿用掌握度算作新证据。
- **端口冲突怎么办？** 桌面程序从 8173 开始查找可用端口；源码一键启动可通过 BACKEND_PORT 和 FRONTEND_PORT 指定其他端口。
- **数据保存在哪里？** 桌面应用通过“应用 → 打开用户数据目录”查看；源码默认在 `data/`。本交付包不包含运行数据库，首次启动自动生成。
- **导出失败怎么办？** 确认本地目录可写，查看后端日志。部分高级 PDF 渲染依赖属于可选能力，以当前导出入口和运行结果为准。
