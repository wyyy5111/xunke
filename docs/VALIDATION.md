## 页面检查

通过 Playwright 在实际浏览器中访问本地静态服务器；网站位于仓库子路径，服务器不运行 Python。以三种角色检查 35 次页面加载，包括深层链接刷新。

- 管理员：数据看板、用户、配置、任务与调用日志。
- 教师：课程管理、资料、知识点、图谱、资源、审核、题库、班级统计与实验页。
- 学生：工作台、设置、前测、画像、路径、讲义、导图、练习、错题、后测、对比、任务与报告。
- 学生浏览三门原有课程的讲义，Markdown 下载成功，PDF 预览打开成功。
- 核对桌面界面及 390 像素宽的移动布局；原有 Vue 样式块未改动。
- 点击生成和任务启动时明确提示需要完整服务；已有展示数据继续保留。
- 损坏的展示会话能自动回到仓库子路径下的登录页，保留原访问路径，未跳到域名根目录。

展示快照包含 4 个公开体验账号、297 个接口响应记录、15 份去重后的报告文件。记录包含原接口正常的权限响应和“测评已完成”状态；不将这些状态替换成伪造的成功结果。

## 与原交付程序的关系

原有前端、后端、桌面端、课程素材与脚本完整保留。原 README 归档于 `docs/archive/原交付源码说明.md`；根目录 README 改为 GitHub 使用说明。适配集中在请求层、路由、展示会话、构建脚本及必要的展示提示。
